# Method

1. Hash-pin the terminal formal raw outputs.
2. Parse `logbook.json` and traverse every page reachable from its root.
3. Resolve every local Markdown evidence link from the candidate root.
4. Require the exact fixed command, visibility matrix, score forecast, claim
   verdicts, executable code, raw data, checkers, controls, limitations, seeds,
   Git/run identity, and CPU/GPU disclosure.
5. Prove all 13 protected judged paths remain in a fresh reconstructed tree.
6. Scan uploaded text for credential-shaped strings without printing matches.
7. Require the second evaluator-blind traversal to pass after the first pass's
   release-file failures were repaired.

Every failed condition makes the verifier exit nonzero.
